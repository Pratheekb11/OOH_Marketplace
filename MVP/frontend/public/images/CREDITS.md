# Image credits

Landing-page photography is from [Pexels](https://www.pexels.com/license/), which
grants free use for commercial and non-commercial work with no attribution
required. The credits below are kept anyway so a photo can be traced, re-fetched
at a different size, or replaced.

These replaced a set of AI-generated placeholders whose billboards carried
garbled lettering ("PREMIUM ON WRK", "MG ROLI"), which is exactly the detail a
visitor to an out-of-home marketplace looks at first.
